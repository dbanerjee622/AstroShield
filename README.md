# AstroShield — Debris Field Simulator

A sensor simulator seen from a rocket: debris flies through a field bent by
the gravity of nearby planets, and you write the code that predicts each
piece's trajectory from the sensor readings. 

Our Inspiration :
As space exploration continues to grow, one of the most escalating threats is posed by space debris and the potential danger it has on future space missions. This inspired us to create a system called AstroShield, which could detect incoming debris and actively prevent collisions with a spacecraft.

What It Does : 
AstroShield utilizes real-time space debris tracking data generated by a realistic simulation to analyze the trajectory of the orbital debris. When a potential collision is detected, the system deploys a kinetic impactor projectile (Tungsten Ball) to alter the debris trajectory and reduce the risk of collision with the spacecraft.

Challenges We Ran Into :
One of the major challenges we encountered during the process of designing AstroShield was finding a reliable way to predict the trajectory of the debris that could collide with the rocket. There are thousands upon thousands of floating space debris which pose a massive threat in the atmosphere, and trying to calculate the trajectory of each one would be near impossible. To solve this, we found a general equation : a(deb_r,t) = Σᵢ((G·M·(π(t)-deb_r))/(|π(t)-deb_r|³) : which represents the trajectory of all space debris through fillable variables.

## Where things live

```
src/
  trajectory.js     <- your code: calculateTrajectory(reading, env)
  prediction.js     calls your code and checks what it returns
  config.js         default settings (the sliders edit these live)
  state.js          shared UI state (paused, selection, visibility toggles)
  main.js           wires everything together and runs the frame loop
  sim/              physics + sensor, no drawing
    simulator.js    debris spawning, stepping, sensor scans ("INTERCEPTOR" hooks)
    bodies.js       sun/planet definitions, orbits, gravity
    math.js         rounding and seeded RNG
  render/           three.js scene
    stage.js        renderer, camera, controls, sky, lights
    rocket.js  planets.js  debris.js  overlays.js  textures.js
  ui/               DOM panels
    hud.js          top bar, sensor feed, detail panel, planet tables
    controls.js     sliders, toggles, buttons, click-to-select
    notify.js       toasts and impact flash
    format.js       number/unit formatting
  styles/           base (tokens), layout, panels, view
```

`window.sim` and `window.CONFIG` are exposed for poking around in the browser console.
